`--info` is a blue that reads as blue. In the Muen theme it was `#1b2a4a` in light mode — a near-black
navy that is indistinguishable from ink at small sizes, so any status mark using `info` looked unstyled.
Light is now `#2c5fd6` (white `--info-foreground`), dark is `#8fb0ee` (near-black foreground), both
holding contrast for text and for icons.
